# stand.fm アカウント構築設計書 — 椎葉ともこ

> 「整える時間」を、声で信頼に変えるための実務マニュアル。

## 0. このチャンネルの役割

椎葉ともこの2つの仕事を、音声で“信頼の貯金”に変える場所。

- **B2B**: スピ系セラピスト・占い師・講師さん向けに、AI 発信アシスタント制作・AI 活用相談につなげる
- **B2C**: 悩み相談・カードリーディングに関心のある人へ、思考と感覚を整える入口をつくる
- **共通**: 売り込みではなく「この人の声・温度感が合う」と感じてもらうこと

短期バズではなく、Instagram / Threads / note / Coconala と将来のPodcast展開をつなぐ“声のハブ”として運用する。

## 1. 押さえておく「伸びる型」

### 1-1. チャンネル名の型

| 型 | 例の方向性 | 強み | 採用箇所 |
| --- | --- | --- | --- |
| 誰向け明示型 | 感覚派のためのビジネス／ひとり起業家へ | 初見で対象が分かる | 各エピソードのサブラベルで使う |
| 状態ラベル型 | 脱感覚派／方向性迷子 | 「自分のことだ」と思われやすい | サムネのラベル |
| 人名＋研究所/放送局型 | 〇〇の思考チャンネル | 権威・継続感 | 本名認知が積まれたら検討 |
| ベネフィット直球型 | AIで売れる／自然と売れる | クリック理由が明確 | 強すぎ注意。サブで部分採用 |
| 世界観型 | 整える時間／本音覚醒 | 記憶に残る | **本命。チャンネル名はここ** |

**結論**: チャンネル名は **世界観型 ＋ 本名**、エピソード単位で **誰向け明示型** を併用する。

### 1-2. プロフィール文の型（伸びている人の順番）

1. 誰のための番組か
2. 何が変わるのか
3. 配信者の実績・背景
4. 配信テーマ
5. 無料特典・サービス導線
6. SNS・問い合わせ先

椎葉さんの場合、実績を強く先に置くと世界観が硬くなる。**冒頭は「整う／ほどける／感覚を言葉に」から入り、実績は中盤の信頼材料として置く**。

### 1-3. Podcast 展開で詰まらない設計

- カバーは小さく表示される前提。**文字は最大3要素**まで
- Apple / Spotify を見据えるなら **3000×3000px 正方形**で作り、stand.fm 用に縮小して使う
- エピソードサムネは「連載感」と「今回の対象者」を瞬時に伝える
- タイトルは検索キーワードより**悩みの入口**を先に置く
- 概要欄は毎回テンプレ化し、聞いた後の行動を**1つだけ**置く

## 5. 見た目の設計

### 5-1. 全体トーン

- **キーワード**: 整う／ほどける／感覚／言葉／AI／カード／信頼／静かな前進
- **避けるもの**: 派手なスピ感／占いだけに寄る／AIのサイバー感／煽りビジネス色
- **フォント**: Noto Sans JP Bold / Black を基本、明朝はアクセント程度

### 5-2. カラーパレット（コピー&ペースト可）

| 役割 | カラー |
| --- | --- |
| メイン（B2B寄り） | `#a51e6d` ／ `#c06299` ／ `#f6e9f0` |
| 文字 | `#333333` ／ `#474747` |
| 補助（B2C寄り） | `#039578` ／ `#e6f4f2` |

### 5-3. 画像サイズの早見表

| 用途 | サイズ | メモ |
| --- | --- | --- |
| stand.fm チャンネルアイコン | 600×600px | 顔出し or 葉モチーフのロゴ |
| stand.fm ヘッダー | 1500×500px | 端から5%は文字を入れない |
| Podcast 番組カバー（将来用） | 3000×3000px | sRGB／PNG or JPG |
| エピソードサムネ | 1280×1280px（正方形） | 3000×3000で作って縮小すると楽 |

### 5-4. ヘッダー画像（1500×500px）

- メイン: `整える時間`（中央やや左／明朝大）
- サブ: `感覚を、言葉とAIで整える音声メモ`（下部）
- 表記: `椎葉ともこ`（右下）
- モチーフ: 葉脈／小さなカード／細い光／余白
- 構図: 端から 5% 以上の余白を必ず確保

### 5-5. Podcast 番組カバー（3000×3000px）

- 文字は最大3要素まで:
  1. `整える時間`
  2. `椎葉ともこ`
  3. `言葉とAIで感覚を整える`
- 下部20%には重要文字を置かない（再生UIで隠れる）
- 縮小表示で「番組名」「世界観」が読めれば合格

## 6. エピソードサムネ設計（B2B / B2C を一目で分ける）

### 6-1. B2B サムネ — サブブランド「**つくる時間**」

| 項目 | 内容 |
| --- | --- |
| 対象 | スピ系セラピスト・占い師・講師・ひとり起業家 |
| 感情入口 | 発信したいのに言葉が軽くなる／AIで自分らしさが消える |
| 役割 | AI 発信アシスタント制作、AI 相談、Coconala 導線 |
| 色 | ブランドピンク濃いめ ＋ 白 ＋ `#333333` |
| モチーフ | チャット吹き出し／3ステップ／文章メモ／きらめき1点 |
| ラベル | `スピ系さん向けAI` / `AI発信` |
| メインコピー例 | `AIに書かせると軽くなる理由` |
| サブコピー例 | `自分の世界観を渡す3点セット` |

### 6-2. B2C サムネ — サブブランド「**ほどく時間**」

| 項目 | 内容 |
| --- | --- |
| 対象 | 迷い・人間関係・選択でぐるぐるしている人 |
| 感情入口 | 考えすぎて眠れない／決めたいのに決められない |
| 役割 | カードリーディング、レター、相談導線 |
| 色 | アイボリー ＋ くすみピンク ＋ 補助グリーン `#039578` |
| モチーフ | カード1枚／葉／余白／手元のメモ |
| ラベル | `カードと思考整理` / `悩みをほどく` |
| メインコピー例 | `眠れない夜のほどき方` |
| サブコピー例 | `書く・歩く・カード1枚` |

### 6-3. 共通サムネ

- ラベル: `整える時間`
- 用途: 自己紹介回／お便り回／振り返り回
- メインコピー例: `二つの“整える”の話`

### 6-4. サムネ テンプレ（Canva に保存して使い回す）

**B2B 用**
```
左上ラベル: スピ系さん向けAI
メインコピー: AIに書かせると軽くなる理由
サブコピー : 世界観を渡す3点セット
右下      : 椎葉ともこ｜整える時間
背景      : ブランドピンク面 + 白いメモ風パーツ
```

**B2C 用**
```
左上ラベル: 悩みをほどく
メインコピー: 眠れない夜のほどき方
サブコピー : 書く・歩く・カード1枚
右下      : 椎葉ともこ｜整える時間
背景      : アイボリー + 淡いカード/葉モチーフ
```

### 6-5. 制作ルール（迷ったら立ち返る）

- 1枚 1メッセージ
- メインコピーは **10〜16文字**
- ラベルは小さく、でも B2B / B2C 判別ができる位置に固定
- 装飾は最大2点。意味のない光・粒・キラキラを増やさない
- フチ文字／強いグロー／読めない装飾文字は禁止
- **55px 程度の小表示で、番組名 or メインコピーのどちらかが読めること**

## 7. エピソードタイトル設計


- `怪しくならない自己紹介文のつくり方`

- `思考がループして眠れない夜のほどき方`

- `頑張れない日は、ダメな日じゃない`
- `カードに聞く前に、先に整理すること`
- `人間関係で同じパターンを繰り返す時`
