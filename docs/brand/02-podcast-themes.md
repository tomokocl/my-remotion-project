# ポッドキャスト企画 — 椎葉ともこ

## 番組コンセプト

- **番組名（案）**: 「カードと AI と、わたしの仕事」
- **サブタイトル**: 個人事業主の女性のための、やさしい“次の一手”ラジオ
- **配信頻度**: 週1回 月曜朝 7:00（通勤・家事の時間に届く）
- **1本の長さ**: 15〜20分
- **構成テンプレ（毎回固定）**:
  1. オープニング（30秒）— 椎葉ともこです、今日のテーマ予告
  2. 今週の1枚引き（2分）— カードを引いて今週の指針を伝える
  3. 本編トーク（10〜12分）— その日のテーマ
  4. AI ワンポイント（2分）— 今日から使える ChatGPT プロンプト1個
  5. お便り紹介＆エンディング（1〜2分）— Coconala / Threads / note 誘導
