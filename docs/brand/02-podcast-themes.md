# ポッドキャスト企画 — 椎葉ともこ

## 番組コンセプト

- **番組名（案）**: 「整える時間」
- **サブタイトル**: 感覚を言葉とAIで整える、椎葉ともこのラジオ
- **聴いてほしい人（2軸）**:
  - **A. スピ系セラピスト・占い師・講師**: AI を世界観のまま使いたい人
  - **B. 仕事・人間関係・人生・メンタルで思考がループしがちな人**: そっと外の視点が欲しい人
- **配信頻度**: 週1回 月曜朝 7:00
- **1本の長さ**: 15〜20分
- **構成テンプレ（毎回固定）**:
  1. オープニング（30秒）— 椎葉ともこです、今日のテーマ予告
  2. 今週の“ひと整え”（2分）— 1枚カードや一節の言葉で今週の指針
  3. 本編トーク（10〜12分）— その日のテーマ
  4. **今日の処方**（2分）— B2B回ならプロンプト、B2C回なら問いかけや小ワーク
  5. お便り紹介＆エンディング（1〜2分）— Coconala（AI制作 / カードリーディング）/ Threads / note 誘導

## 番組名 別案

1. **「整える時間」**（推奨／両軸を内包）
2. 「世界観のままAIで」（B2B寄り）
3. 「感覚と言葉のあいだ」
4. 「葉っぱの下のラジオ」
5. 「ともこの整え部屋」

## 二軸の運用ルール

- **配信パターン**: 隔週で B2B 回／B2C 回を交互配信（Season単位では 4:4 で 5:5 比率）
- **冒頭の宣言**: 各回のオープニングで「今日はセラピストさん向け／悩みを抱えているあなた向け」と一言入れる
- **共通の“ひと整え”**: 番組頭の1枚引きは両軸共通の入口として機能させる
- **CTA**: B2B 回は AI 制作サービス、B2C 回はカードリーディングへ誘導
