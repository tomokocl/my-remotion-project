# Threads 投稿案 — 椎葉ともこ

## プロフィール文（500文字以内）

```
椎葉ともこ｜感覚を言葉とAIで整える人
スピ系セラピスト・占い師・講師のための、AI 発信アシスタント制作。
ChatGPTで“自分の言葉が薄まる”を、世界観のままAIで動ける形へ。
🌿 3.3万人規模のスピ系Instagram運用経験／AI講師
🃏 投稿・募集文・商品説明のプロンプト処方を毎週
個別相談・GPTs 制作 → プロフリンクから
※売上・集客の保証はしません。整える専門です。
```

## 投稿の型（4パターン）

1. **共感フック型**: 「〜な経験ありませんか？」で始める
2. **プロンプト処方型**: そのままコピペできるプロンプトを1つ
3. **世界観Tips型**: スピ系の言葉を AI で扱う際のコツ
4. **裏側エピソード型**: 3.3万アカ運用や受注体験からの気づき

## 投稿サンプル 30本

### 共感フック型（×8）

1. ```
   「ChatGPTで募集文を書いたのに、結局ぜんぶ書き直した」
   そんな夜、ありませんか？
   AI の言葉が悪いんじゃなく、
   “あなたの世界観”をまだ AI に渡せていないだけです。
   ```

2. ```
   スピ系の文章をAIに書かせると
   ・軽くなる
   ・強くなる
   ・怪しくなる
   この3つのどれかに振れます。
   間を取る方法、ちゃんとあります。
   ```

3. ```
   「整う」「ゆるむ」「受け取る」
   この3語、AIは平気で“整理する／緩める／受領する”に直してきます。
   ニュアンスごと運ぶには、語彙を“辞書”にして渡すのがコツです。
   ```

4. ```
   セッションは満席なのに、
   募集文だけ書けない日があります。
   それは才能の問題じゃなく、
   毎回ゼロから考えているからです。
   テンプレを“自分用に持つ”だけで、ぜんぶ変わります。
   ```

5. ```
   「AIに頼むと売り込みっぽくなる」
   それ、AIのせいじゃありません。
   渡したお手本がセールス文ばかりだから、です。
   3投稿だけ、自分の過去投稿を読ませてみてください。
   ```

6. ```
   発信を休んだ週、
   売上が落ちなかったセラピストさんは多いです。
   「毎日投稿しなきゃ」を一度ゆるめると、
   AI の使い方も変わります。
   ```

7. ```
   「スピって書くと怪しいって思われそう」
   その遠慮が、言葉を曖昧にします。
   AIに“ぼかさず、断定もしない言い方”を頼んでみてください。
   ちょうどいい温度、出せます。
   ```

8. ```
   自分の世界観を、人に説明するのは難しい。
   でも、AIになら少しずつ渡せます。
   時間はかかるけれど、一度渡せば、毎日手伝ってくれる相棒になります。
   ```

### プロンプト処方型（×8）

9. ```
   【投稿の温度を保つ最小プロンプト】
   「以下の文を、〇〇さんの世界観で書き直してください。
   ・語尾: ですます／断定しすぎない
   ・避けたい言葉: 絶対／必ず／〜べき
   ・残したい言葉: 整える／ゆるむ／受け取る」
   これを毎回貼るだけで、別人化を防げます。
   ```

10. ```
    【募集文の骨組みを作るプロンプト】
    「以下の5項目で募集文の構成だけ作ってください。
    ①どんな人へ ②現状の悩み ③受け取れるもの
    ④3日後・1週間後の変化 ⑤参加方法と注意点」
    文章はあとで自分の言葉に置き換えます。
    ```

11. ```
    【商品説明の冒頭3行プロンプト】
    「次の商品を、3行で“怪しくなく・薄くなく”紹介してください。
    対象は〇〇／核は〇〇／読後に感じてほしい温度は“安心”。」
    冒頭が決まると、続きが書けます。
    ```

12. ```
    【自分の語彙辞書プロンプト】
    「これからの会話では、以下の語をそのまま使ってください。
    『整う／ゆるむ／受け取る／ちょうどいい／腑に落ちる』
    類義語への置き換えはしないでください。」
    1行目に貼ると、ニュアンスが守られます。
    ```

13. ```
    【投稿ネタを10案出すプロンプト】
    「私の仕事は〇〇です。
    過去の投稿でよく使うキーワードは△△です。
    このキーワードを使った投稿テーマを10個、見出しだけ作ってください。」
    朝3分で、1週間分のネタが揃います。
    ```

14. ```
    【プロフィール文の温度直しプロンプト】
    「以下のプロフ文を、強くも軽くもなく、
    ふっと安心するトーンに整えてください。
    400字以内、敬語、断定なし。」
    肩書きを変えるよりも、まずは温度から。
    ```

15. ```
    【お礼DMテンプレを世界観で作るプロンプト】
    「セッション後のお礼DMを3パターン。
    ①余韻を残す ②次回を案内 ③紹介をお願い
    語尾は丁寧、押しは弱め。絵文字は1つまで。」
    手が止まりがちな部分、AI で型にできます。
    ```

16. ```
    【NGワード除去プロンプト】
    「以下の文章から、医療的・診断的・過剰な断定表現を取り除き、
    意味を変えずに整えてください。」
    スピ系の発信、これを最後に必ず通すと安心です。
    ```

### 世界観Tips型（×8）

17. ```
    AIに世界観を渡す3点セット
    ① 過去の自分の投稿3本
    ② 使う／使わない言葉のリスト
    ③ お客様の声1本
    これだけで、別人化はほぼ止まります。
    ```

18. ```
    “ふんわり”と“ぼんやり”は違う。
    ふんわり=温度がやわらかい
    ぼんやり=意味が見えない
    AIが出してくるのは、後者になりがちです。
    意味は明確に、温度はやわらかく、と頼みます。
    ```

19. ```
    募集文に必ず入れたい3行
    ① これは誰のためか
    ② 何が受け取れるか
    ③ 何を保証しないか
    ③があると、信頼が落ちません。
    ```

20. ```
    スピ系で避けたい3つの言葉
    ① 絶対／必ず（断定）
    ② 〜してください（強い命令）
    ③ 〜なはず（決めつけ）
    AI に「この3つを使わずに書いて」と頼むだけで全体が整います。
    ```

21. ```
    投稿が同じになる人の共通点
    ① 書く前にAIに“まとめさせている”
    ② テーマじゃなく“結論”を先に決めている
    ③ 自分のメモを使わず、ゼロから書いている
    順序を変えるだけで、抜けます。
    ```

22. ```
    “世界観の翻訳”は、3ステップ
    ① 自分の言葉で書く
    ② AIに「意味を変えず、整えて」と頼む
    ③ 出てきた文の“1割”だけ、自分の温度に戻す
    全部任せず、最後の1割を残す。
    ```

23. ```
    GPTsに渡したい“前提”の3要素
    ① 私の仕事の核（1文）
    ② お客様の核（1文）
    ③ 私が使わない言葉（5語まで）
    たった3行で、応答が安定します。
    ```

24. ```
    AIが書いた文を“自分の文”にする最後の確認
    ・声に出して読む
    ・心拍が上がる箇所を探す
    ・上がらなければ、温度を1段上げる
    最後は身体で決めて大丈夫です。
    ```
