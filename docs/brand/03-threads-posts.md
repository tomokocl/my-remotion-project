# Threads 投稿案 — 椎葉ともこ

## プロフィール文（500文字以内）

```
椎葉ともこ｜感覚を言葉とAIで整える人
🌿 スピ系セラピスト向け：AI発信アシスタント制作（GPTs/プロンプト設計）
🃏 悩める方向け：テキスト納品のカードリーディング（準備中→近日公開）
ChatGPTで“自分の言葉が薄まる”を、世界観のままAIで動ける形へ。
ループする思考に、カード3枚で“次の一歩”を。
3.3万人規模のスピ系Instagram運用／AI講師
個別相談・サービス → プロフリンクから
※売上・集客・特定の結果の保証はしません。整える専門です。
```

## 投稿の比率と曜日割り

- **B2B : B2C = 6 : 4**
- 曜日例（週7投稿の場合）:
  - 月・火・水・木: B2B（プロンプト処方／世界観Tips／募集文の話）
  - 金・土・日: B2C（1枚引き／思考のループほどき／お悩み共感）

## 投稿の型（5パターン）

1. **共感フック型**（両軸）
2. **プロンプト処方型**（B2B）
3. **世界観Tips型**（B2B）
4. **1枚引き／カード型**（B2C）
5. **悩みほどき型**（B2C）／**裏側エピソード型**（両軸）

### B2B：プロンプト処方型（×5）

5. ```
   【投稿の温度を保つ最小プロンプト】
   「以下の文を、〇〇さんの世界観で書き直してください。
   ・語尾: ですます／断定しすぎない
   ・避けたい言葉: 絶対／必ず／〜べき
   ・残したい言葉: 整える／ゆるむ／受け取る」
   毎回これを貼るだけで、別人化を防げます。
   ```

6. ```
   【募集文の骨組みプロンプト】
   「以下の5項目で募集文の構成だけ作ってください。
   ①どんな人へ ②現状の悩み ③受け取れるもの
   ④3日後・1週間後の変化 ⑤参加方法と注意点」
   文章はあとで自分の言葉に置き換えます。
   ```

7. ```
   【商品説明の冒頭3行プロンプト】
   「次の商品を、3行で“怪しくなく・薄くなく”紹介してください。
   核は〇〇／読後に感じてほしい温度は“安心”。」
   冒頭が決まると、続きが書けます。
   ```

8. ```
   【自分の語彙辞書プロンプト】
   「これからの会話では、以下の語をそのまま使ってください。
   『整う／ゆるむ／受け取る／ちょうどいい／腑に落ちる』
   類義語への置き換えはしないでください。」
   ニュアンスが守られます。
   ```

9. ```
   【NGワード除去プロンプト】
   「以下の文章から、医療的・診断的・過剰な断定表現を取り除き、
   意味を変えずに整えてください。」
   スピ系の発信、これを最後に通すと安心です。
   ```
