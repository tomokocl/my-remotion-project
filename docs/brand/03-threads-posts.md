# Threads 投稿案 — 椎葉ともこ

## プロフィール文（500文字以内）

```
AI ×カードリーディングで、女性ひとり起業の「次の一手」を整える人／椎葉ともこ
ChatGPT で頭を整理して、カードで気持ちを整える。両方やります。
🌿 値付け・SNS・断り方の悩みに寄り添うラジオ毎週月曜
🃏 1枚引きの“今週のヒント”は毎週日曜
個別相談 → プロフリンクから
```

## 投稿の型（4パターン）

1. **共感フック型**: 「〜な日、ありませんか？」で始める
2. **Tips 型**: 番号付きで3つ提示（最後にプロンプト or 問い）
3. **カード引き型**: 「今日引いたカードは○○」
4. **裏側エピソード型**: 失敗談・気づきを200字で
