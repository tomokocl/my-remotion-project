# 椎葉ともこ｜感覚を言葉とAIで整える人 — ブランド設計ドキュメント

「整える」一本の幹で、**スピ系セラピスト向けAI制作（既存）**と、**悩める人向けカードリーディング（新規）**の二つの仕事をひとつのチャネルで運用するための設計集です。

## 前提

- **公開名**: 椎葉ともこ
- **肩書き**: 感覚を言葉とAIで整える人
- **二つのサービス**:
  - **① B2B（既存）**: スピ系セラピスト・占い師・講師 向けの AI 発信アシスタント制作（GPTs／プロンプト設計）→ [Coconala](https://coconala.com/services/3659900)
  - **② B2C（新規）**: 非同期テキストのカードリーディング（仕事／人間関係／人生／メンタル） → 設計書は `05-card-reading-service.md`
- **強み**: スピ系 Instagram 3.3万人運用、AI 講師、AI 活用サポート、ツール制作、Coconala 総販売 6 件
- **トーン**: フレンドリー・寄り添い型／敬語ベース／断定を控える
- **免責**: 売上・集客・特定の結果の保証はしない／医療・診断・法律・金融は扱わない

## 二軸ブランドの構造

```
                  椎葉ともこ
              ┌──「整える」──┐
              │              │
        ① 世界観を整える    ② 気持ちを整える
        (B2B / AI制作)     (B2C / カードリーディング)
              ↓               ↓
        セラピスト         悩める個人
```

## 発信フロー

```
Instagram(既存3.3万)   ← 認知の母艦
       ↓ プロフリンク
note(月2-4本・長文・SEO) ← 検索流入・資産
       ↓ 引用 200字 + リンク
Threads(毎日・短文)      ← 人柄と継続接触
       ↓ 「詳しくはラジオで」
Podcast(週1・15-20分)    ← 信頼の醸成
       ↓ 概要欄リンク
Coconala (2サービス)     ← 受注・クロージング
   ├ AI 制作サービス（B2B）
   └ カードリーディング（B2C・準備中）
```
