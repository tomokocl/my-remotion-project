# note コンテンツ企画 — 椎葉ともこ

## 運用方針

- **役割**: 検索流入と“資産化”。Threads（流量）に対し note は“読み返される場”。
- **対象読者（2軸）**:
  - **A. スピ系セラピスト・占い師・講師**（B2B）
  - **B. 仕事・人間関係・人生・メンタルで悩んでいる方**（B2C）
- **頻度**: 月 2〜4 本（週1ペース）
- **長さ**: 2,000〜4,000 字
- **比率**: B2B : B2C = **6 : 4**（月4本なら 2.5 : 1.5、隔月で 2:2 にしてもOK）
- **構成テンプレ**:
  1. 共感の導入（200字）
  2. 結論を先に（100字）
  3. 理由・体験談（1,200字）
  4. 今すぐできる手順／プロンプト（800字／番号付き）
  5. まとめ＋Coconala / Podcast へのリンク＋免責文（200字）
- **マガジン構成**:
  - 「整える時間」（メイン・無料／全記事）
  - 「世界観のままAIで」（B2B特化／無料）
  - 「カードと、整える話」（B2C特化／無料）
  - 「セラピストのためのAI実例集」（有料・月額500円・B2B）

## プロフィール文（note 用 400字）

```
椎葉ともこ｜感覚を言葉とAIで整える人
スピリチュアル系セラピスト・占い師・講師向けに、AI 発信アシスタント（GPTs／プロンプト設計）を制作。

```

## 記事企画 12本（3か月分）

### 月1: 立ち上げ期 — 認知と信頼

1. **【自己紹介】二つの“整える”をやっている理由——AIとカードと、わたし** (両軸)
   - 自身の軌跡／二軸ブランドの説明／読者へのお約束
   - CTA: ポッドキャスト Ep.1

2. **ChatGPT で“自分の世界観が薄まる”理由と、最初に渡すべき3つの情報** (B2B)
   - SEO 狙い（「ChatGPT 世界観」「ChatGPT 自分っぽくない」）
   - “世界観メモ”テンプレ配布
   - CTA: マガジン登録／AI 制作サービス

3. **「辞めるか続けるか」をカードに聞く前にやる、5つの整理** (B2C)
   - SEO 狙い（「辞めるか続けるか 仕事」「決められない 悩み」）
   - 整理のフォーマット配布
   - CTA: カードリーディング（準備中）

4. **AIで募集文を書くと“売り込みっぽくなる”ときに直す3つの順番** (B2B)
   - そのまま使えるプロンプト3つを掲載
   - CTA: Coconala（AI 制作）

### 月2: 拡張期 — 検索流入とサービス想起

5. **【テンプレ配布】スピ系セラピスト向け・商品説明の“3層構造”** (B2B)
   - 機能／感情／世界観の3層／実例つき
   - CTA: メルマガ登録

6. **思考のループを止めるカードの引き方（1枚引きの実例つき）** (B2C)
   - SEO 狙い（「タロット 1枚引き」「悩み カード」）
   - CTA: カードリーディング

7. **「整う」「ゆるむ」「受け取る」をAIにそのまま使わせる方法** (B2B)
   - 語彙辞書プロンプトの作り方
   - CTA: マガジン

8. **電話占いが怖い人のための、テキストカードリーディングという選択肢** (B2C)
   - 新サービス紹介記事／差別化

### 月3: 収益化期 — Coconala 流入と有料化

9. **【有料 500 円】Coconala の商品ページを“相談DMが増える”形に書き直した全工程** (B2B)
   - ビフォーアフター・LP構成・使ったプロンプト全公開
   - 月額マガジン登録への入口

10. **人間関係で同じパターンを繰り返す人へ、カードと言葉でほどく3ステップ** (B2C)
    - SEO 狙い（「人間関係 ループ」「同じパターン 繰り返す」）
    - CTA: カードリーディング

11. **AIに“あなた専用”を覚えさせる4つのレイヤー（人格／語彙／お客様像／NG）** (B2B)
    - GPTs 設計の解説
    - CTA: GPTs 制作（Coconala）

12. **【まとめ】3か月で書いた11本、反応の良かった順に解説** (両軸)
    - メタ記事／コミュニティ感の醸成

## 表紙画像テンプレ

- サイズ: 1280×670
- 構成: 左寄せ大きめタイトル（明朝）＋右に葉脈／光／カードのモチーフ
- カラー: アイボリー＋薄墨＋差し色くすみピンク or ゴールド
- ツール: Canva のテンプレを B2B用／B2C用 で2種類用意

## 投稿後の運用

1. 公開当日 — Threads に冒頭200字＋note リンクを引用形式で投稿
2. 翌日 — ポッドキャストの該当回で言及
3. 1週間後 — note の反応をもとに Coconala の商品文面を 1 か所だけ修正
4. 1か月後 — アクセス上位3本を Threads で再掲

## 有料マガジン設計（月額 500 円・B2B 特化）

- **対象**: 「もう一歩深く知りたい」既存読者
- **内容**: 月2本／クライアントワーク or 自身の事例を匿名化／GPTs ／プロンプト全文公開
- **特典**: 毎月1回の「お便り回答会」／限定プロンプトテンプレ配布
- **数値目標**: 90日で20名（売上 1万円/月）

> B2C にも有料化の余地はあるが、最初は「無料で読める信頼の場」に徹したほうがカードリーディング購入につながりやすい。
