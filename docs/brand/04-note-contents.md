# note コンテンツ企画 — 椎葉ともこ

## 運用方針

- **役割**: 検索流入と“資産化”。Threads のフロー型に対し、note はストック型。
- **頻度**: 月 2〜4 本（週1ペースが理想）
- **長さ**: 2,000〜4,000 字（読了 5〜8 分）
- **構成テンプレ**:
  1. 共感の導入（200字）
  2. 結論を先に（100字）
  3. 理由・体験談（1,200字）
  4. 今すぐできる手順（800字／番号付き）
  5. まとめ＋Coconala / Podcast へのリンク（200字）
- **マガジン構成**:
  - 「AI×カードで整える、ひとり起業」(メイン)
  - 「今週の1枚」(Podcast 連動の短文／無料)
  - 「クライアントワークの裏側」(有料・月額500円)

## プロフィール文（note 用 400字）

```
椎葉ともこ｜AI × カードリーディングで、女性のひとり起業を“やさしく整える”人。
ChatGPT で頭を整理し、タロットで気持ちを整える、両利きの相談相手です。
SNS・値付け・断り方など「ひとりで考えるとループする」悩みに寄り添います。
🌿 週1ポッドキャスト「カードと AI と、わたしの仕事」配信中
🃏 個別相談 → Coconala プロフィールリンクから
迷ったら、まずは note の記事を1本どうぞ。
```

## 記事企画 12本（3か月分）

   - CTA: ポッドキャスト Ep.1

2. **個人事業主の「頭が散らかる」を3分で整える、ChatGPT プロンプト5選**
   - SEO 狙い（「ChatGPT プロンプト 個人事業主」）
   - 全プロンプトコピペ可で配布
   - CTA: マガジン登録

3. **値上げが怖い人へ。私が Coconala で価格を上げた夜の話**
   - エピソード型／カード＋ AI の意思決定プロセス公開
   - CTA: 個別相談

4. **「占いは胡散臭い」と思っていた私が、カードを仕事に取り入れた理由**
   - スピ×ロジックの境界を扱う／信頼獲得記事
   - CTA: ポッドキャスト

### 月2: 拡張期 — 検索流入とサービス想起

5. **ChatGPT で“事業の年表”を作るワークシート（プロンプト付き）**

8. **私がやめた SNS 3つと、続けている SNS 1つの話**

## 表紙画像テンプレ

- サイズ: 1280×670（note 推奨）
- 構成: 左寄せ大きめタイトル＋右にカード or グラフのワンモチーフ
- カラー: ベージュ背景＋ネイビー文字＋差し色くすみピンク
- ツール: Canva のテンプレを 1 つ作って毎回流用

## 投稿後の運用

1. 公開当日 — Threads に冒頭200字＋note リンクを引用形式で投稿
2. 翌日 — ポッドキャストの該当回内で言及
3. 1週間後 — note の反応をもとに Coconala の商品文面を 1 か所だけ修正
4. 1か月後 — アクセス上位3本を Threads で再掲（保存数狙い）

- **特典**:

  - 限定プロンプト配布
- **数値目標**: 90日で20名（売上 1万円/月 → 安定したら値上げ）
