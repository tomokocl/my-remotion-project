# Google Calendar 一方向同期（A → B）

アカウントA（社内メイン）の予定を、アカウントB（個人・社外共有用）に「予定あり」ブロックとして自動同期する Google Apps Script。

## セットアップ（5分で終わります）

### 1. アカウントBのカレンダーをアカウントAに共有する

1. **アカウントB** で Google カレンダーを開く
2. 左の「マイカレンダー」からカレンダーの ⋮ → 「設定と共有」
3. 「特定のユーザーとの共有」→「ユーザーを追加」
4. アカウントAのメールアドレスを入力
5. 権限を「**予定の変更**」に設定して保存

### 2. Google Apps Script にコードを貼る

1. **アカウントA** で https://script.google.com/ を開く
2. 「新しいプロジェクト」を作成
3. 左メニューの「サービス」→「+」→ **Google Calendar API** を追加
4. エディタに `sync.gs` の中身をコピペ
5. `ACCOUNT_B_CALENDAR_ID` にアカウントBのメールアドレスを設定

### 3. 初回実行

1. 関数セレクタで `initialSetup` を選んで ▶ 実行
2. 権限の確認ダイアログが出るので「許可」
3. 「詳細」→「（安全でないページ）に移動」→「許可」

### 4. 自動同期トリガーの設定

1. 関数セレクタで `createTrigger` を選んで ▶ 実行
2. 以上。1分おきに自動同期が始まります。

## 仕組み

- 1分ごとにアカウントAのカレンダーの変更を検出
- 新しい予定 → Bに「予定あり」を作成
- 予定の変更 → Bの「予定あり」の時間を更新
- 予定の削除 → Bの「予定あり」を削除
- Google の Sync Token を使うので、毎回全件取得するわけではなく軽量

## 止めたいとき

Google Apps Script のプロジェクト画面 → 左の「トリガー」→ トリガーを削除
